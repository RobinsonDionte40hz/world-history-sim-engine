# Examples README

This directory contains practical examples demonstrating the Consciousness Engine WASM usage.

## Running Examples

```bash
cd rust-wasm/consciousness-engine
node examples/01-basic-usage.js
node examples/02-batch-processing.js
node examples/03-lod-integration.js
```

## Examples Overview

### 01-basic-usage.js
**Purpose**: Introduction to basic engine usage  
**Topics**: Initialization, single character calculation, performance stats  
**Time**: 2 minutes

### 02-batch-processing.js
**Purpose**: Demonstrates batch processing performance  
**Topics**: Individual vs batch processing, throughput calculation  
**Time**: 2 minutes

### 03-lod-integration.js
**Purpose**: LOD (Level of Detail) tier integration  
**Topics**: Hero, Named NPC, and Population Group processing  
**Time**: 3 minutes
